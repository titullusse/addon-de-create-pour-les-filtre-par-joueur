Un addon Create Mod complet avec:
  ✓ Coffres de tri par joueur
  ✓ Filtres Create automatiques
  ✓ Système de tags NBT
  ✓ Commandes /cpf
  ✓ Code source Java modifiable
  ✓ Documentation complète en français


🚀 DÉMARRAGE RAPIDE (3 ÉTAPES):
───────────────────────────────

1. EXTRAIRE:
   ├─ CreatePlayerFilter.zip (recommandé Windows)
   └─ CreatePlayerFilter.tar.gz (recommandé Linux/Mac)

2. COMPILER:
   ├─ Windows: Double-clique COMPILE.bat
   └─ Linux/Mac: ./COMPILE.sh

3. INSTALLER:
   ├─ Copier build/libs/createplayerfilter-1.0.0.jar
   └─ Dans ~/.minecraft/mods/
