## ⚡ 3 étapes pour démarrer

### 1️⃣ Compiler (2-5 minutes)

**Windows:**
```
Double-clique → COMPILE.bat
```

**Linux/Mac:**
```bash
chmod +x COMPILE.sh
./COMPILE.sh
```

✅ Résultat: `build/libs/createplayerfilter-1.0.0.jar`

### 2️⃣ Installer

1. Copie le JAR dans `mods/`
2. Lance Minecraft NeoForge 1.21.1
3. Cherche "createplayerfilter" dans les mods

### 3️⃣ Tester en jeu

```
/cpf tag <joueur>    → Tagger un item
/cpf untag           → Retirer le tag
```
